Overview

Nexboard is a customizable personal dashboard built with React and Vite that brings multiple everyday utilities into one place. It features draggable, resizable widgets for checking the weather, managing tasks, browsing news headlines, and sketching on a digital whiteboard — all powered by free APIs and persisted with localStorage so your layout is always saved.

The project was built in phases, with each widget developed and tested independently before being integrated into the shared layout system. Using react-grid-layout for the drag-and-drop interface and the Open-Meteo and Google News RSS APIs for live data, the focus was on creating a seamless, responsive experience without needing a backend.

Nexboard reinforced the value of breaking a multi-feature project into small, testable pieces rather than building everything at once. It also gave practical experience working with third-party APIs and deploying a React app to Netlify.
